## 👨‍💻 About Me

I have 15 years of experience in computing, including **5+ years** focused on Data Engineering.
My experience spans multiple industries, including EdTech, Public Sector (Public Prosecution
and Courts of Law), Oil & Gas, Agribusiness, and E-commerce Fraud Prevention, where I have
designed and implemented **scalable data platforms, data pipelines, APIs, and analytics solutions**
that support business-critical decision-making.

Also, I have a solid academic background in **Computer Science, with a Ph.D. (2020)**
focused on Data Science, a **M.Sc. (2015)** and a **Bachelor’s degree (2012)** in
Computer Science focused on Multimedia Systems.

**Core expertise**

- **Programming Languages**: Python, C++, Javascript
- **Cloud & Infrastructure**: AWS (S3, SQS, Lambda, ECS, EKS, CloudWatch), GCP, Docker, Kubernetes
- **Data Processing & Orchestration**: Airbyte, Airflow, Celery, dbt, Spark, Databricks
- **Data Architecture**: Data Lakes, Data Warehouses, Modern Data Stack, Batch Processing, Data Pipelines
- **Databases**: BigQuery, MongoDB, MySQL, PostgreSQL, Redshift, Redis
- **Backend Development**: REST APIs, Microservices, Tornado, FastAPI
- **Analytics & Data Visualization**: Pandas, Power BI, Metabase, Operational Analytics, KPI Monitoring
- **Monitoring & Reliability**: Elementary, Great Expectations, Testing, Observability, SLA/SLO Design

*Interests: data engineering, modern data stack, distributed data processing, data governance.*
